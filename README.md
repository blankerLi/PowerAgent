# PowerAgent

LLM 驱动的多相 Buck 供电模块参数寻优 Agent。

在一个**昂贵、会失败、带硬约束**的仿真环境里，由大模型提出候选参数、由确定性代码做全部安全判定与判分，闭环搜索满足电气约束的设计点，并产出可审计的对比报告。

> **状态：开发中（D1/15）。** 下表是逐日推进的真实进度，不预先宣称未完成的能力。

## 为什么不是又一个 LLM 调用脚本

三个信任域，边界由 Python 包结构强制，不靠约定：

| 域 | 模块 | 权限 | 明确**没有**的权限 |
| --- | --- | --- | --- |
| 确定性域 | `controller` `eval` `store` `report` `config` | 全部安全判定与事实写入 | 不生成候选 |
| LLM 域 | `agent.propose` | 依只读状态输出 3~6 个候选与搜索假设 | 不调仿真、不写状态、不判分、**不决定自己被校验的严格度** |
| 仿真域 | `sim` + MATLAB `+pa` | 唯一有权访问模型文件 | 不接受任意 MATLAB 命令、寻优期只读 |

由此得到的几条性质：

- **判分权与提案权分离**：约束判定、worst-case 聚合、排序全在 `eval`，LLM 不参与，杜绝"自己给自己打分"。
- **LLM 输出必过确定性校验器**：单位量纲归一、合法域裁剪、档位对齐、重复与新颖度检查。被拒候选连同具名拒绝原因落 `rejections` 表，不静默丢弃。
- **两类失败严格分开**：输出不合 schema → 回灌错误清单修复（计入 `max_llm_repair_rounds`）；网络失败/超时 → 指数退避（计入 `max_network_retries`）。两者不混计，网络重试耗尽等价于本轮空候选。
- **上下文按信息而非按长度压缩**：波形采样点禁止进入 prompt，先确定性压缩为 6 个特征（超调/下冲/恢复时间/纹波/振荡频次/发散标志）。
- **prompt 可复现**：相同状态产出逐字节相同的 prompt 文本与 `context_hash`；prompt 与原始输出落盘。
- **成本有闸**：仿真调用次数、墙钟、token 三维度预算账本，触顶熔断；两级缓存键复用昂贵仿真结果。
- **状态可重建**：SQLite 是唯一事实源，进程崩溃后从数据库重建搜索状态，支持断点续跑。
- **分层执行有真实成本梯度**：筛选层用平均模型（不含开关纹波，快 1~2 个数量级），只有通过筛选的候选才进入评价层的开关模型。省下的仿真次数是可测量的，不是纸面设计。
- **模型变更使旧结论失效**：模型依赖闭包的全部文件内容参与 `model_package_hash`，与冻结记录不符即拒绝启动。闭包边界的裁定是"被仿真的对象"进（拓扑与工作点定义、模型引用、封装层），"仿真器实现"不进（求解器代码、MATLAB 版本，后者由运行时配置记录）——把开发中的求解器代码计入闭包会让冻结机制因过度敏感而被绕过。

## 被优化的对象

一个 4 相同步 Buck 变换器，把板级 12 V 中间总线降到 0.8 V 给负载供电，额定 200 A。
待整定的是 Type-II 补偿网络的两个参数 `Rcomp` / `Ccomp`，它们决定环路的零点位置，
进而决定负载突变时输出电压掉多深、多久恢复、以及环路还剩多少稳定性裕量。

| | |
| --- | --- |
| 拓扑 | 4 相交错，每相 500 kHz；L = 150 nH/相，Cout = 6 mF，ESR = 0.15 mΩ |
| 控制 | **电流模式**（电流内环 + 电压外环），Type-II 跨导补偿器 |
| 工况 | 筛选 12 V / 25 °C；评价 10.8 V / 85 °C，负载 100 A → 150 A 阶跃 |
| 设计变量 | Rcomp ∈ [1 k, 100 k] Ω，Ccomp ∈ [100 p, 10 n] F，各 12 个对数档位 → 144 点网格 |
| 硬约束 | Vout ∈ [0.75, 0.85] V；相电流峰值 ≤ 55 A；相位裕量 ≥ 45° |
| 优化目标 | 最小化最恶劣工况下的恢复时间，目标 ≤ 25 µs；并列时比相位裕量 |
| 搜索预算 | 200 次仿真调用（全网格穷举需 288 次），2 小时墙钟，连续 3 轮无改善即停 |

为什么是电流模式而不是电压模式，这一点决定了整个优化问题是否成立：低压大电流的
LC 输出网络阻尼极小（Q ≈ 4），电压模式下这对双极点在穿越频率处贡献 −180° 相位，
而 Type-II 补偿器只有一个零点、最多补回 +90°，**无论怎么整定都拿不到 45° 相位裕量**。
想靠输出电容 ESR 零点补相位，就得把 ESR 加到 mΩ 量级，而那时 ESR×ΔI 的瞬时压降会
直接吃光全部电压容限。电流内环把电感极点消掉、功率级降为一阶，Type-II 才够用。
工业界的 AI 加速器供电模块同样如此。

两个设计变量各管一个方向，可行域被夹在中间：Rcomp 定带宽，太小则下冲超限、太大则
高频开环增益（趋于常数 Rcomp·gm·ESR/Ri）超过 1 而失稳；Ccomp 定补偿零点位置，
太小则零点落在穿越频率之上、补不回相位。

物理数值是自洽的设计假设，量级取自低压大电流 VRM 的常见区间，**未绑定实测数据或
具体器件 datasheet**。所以本项目的结论是"这套搜索方法在该电路上有效"，而不是
"这组参数可以拿去投产"。

## 已知边界

诚实标注，不含糊：

- 阶段 1 为**仿真轨**（`simulation_only=true`）。未做实测校准，结论不足以支撑直接打板。
- 以下模块在范围裁剪中被明确移除，非"待补全"：模型校准、工程知识检索、鲁棒性三维扫描、寄生参数敏感性、双模型一致性的运行期门禁与并行仿真回退。移除理由与取舍记录在 `docs/design/design.md`。
  双模型一致性的**配置校验与 preflight 断言仍在代码中**（`averaged_model_required=false` 时按设计豁免，不读取任何记录）——只是这条路径在本阶段不会被触发。
- MATLAB/Simulink 通路为可选高保真后端。所在环境为共享网络许可证，`Simulink` 并发常满，因此主链路默认走 Python 仿真后端。
- 两处数值偏差已测量并记录在案，未隐藏：开关模型在配置步长（20 ns 显式欧拉）下对负载阶跃下冲高估约 3%（相对 5 ns 的收敛值），方向保守；其初始状态不是精确的稳态相位，需若干开关周期衰减，在配置的 1 ms 仿真时长下残余影响低于 0.5%。双模型一致性容差因此设为 10%，其构成写在配置注释里。
- 频域裕量用精确纯延迟表达采样保持，时域求解用一阶滞后近似它。这个分裂是有意的：纯延迟会把常微分方程变成延迟微分方程，而一阶滞后的相位下界是 −90°，会让增益裕量在数学上无界、进而被下游判为提取失败。
- `agent`（LLM 提案）与 `report`（报告渲染）尚未实现，主循环目前由脚本化的候选序列驱动。

## 已验证的性质

下列都是当前测试套件实际断言的内容（`pytest`，91 项，约 75 秒，无需 MATLAB）：

**分层执行的成本梯度是真实的**：平均模型单次约 7.5 ms，开关模型约 360 ms，**相差
48 倍**。前者不含开关纹波（稳态峰峰值 < 10 µV），后者产生真实纹波（约 1.8 mV）与
相电流三角波（单相峰峰约 11.7 A，与解析值一致），并使相电流峰值抬高约 5 A —— 所以
`peak_current_max` 这条约束只有在评价层才有实际约束力。

**两个保真度描述同一个电路**：稳态输出偏差 0.005%（容差 0.5%），负载阶跃下冲偏差
8.25%（容差 10%）。这份核对是分层执行的前提证据，并已抓到过一个真实错误。

**裕量提取有两条独立路径且完全一致**：数值状态空间线性化与手写解析传递函数，在四个
探测点（含一个不可行点）上偏差为 0.0° / 0.0 dB。

**结果可复现**：同一候选同一场景两次求解逐位相同，且与仿真总时长无关。

**判分链完整**：波形归档 → 五项时域指标 → 频域裕量 → 硬约束判定，工程基线在最恶劣
工况下判为可行（相位裕量 83.5°，增益裕量 16.7 dB）。

**主循环跑通**：`run_task` 完成一次完整寻优，preflight 七条断言全过，预算按调用次数
计入并与数据库求和一致，搜索状态可完全从 SQLite 重建。

## 开发期证据记录

两份记录由脚本产出并入库，各自被 preflight 校验，不是可重建的运行期产物：

```bash
python scripts/margin_cross_check.py       # → artifacts/margin_cross_check.json
python scripts/dual_model_consistency.py   # → artifacts/dual_model_consistency.json
```

前者内容是确定性的（无时间戳、固定小数位、规范化序列化），其 sha256 被
`metrics.yaml` 绑定——一份每次重跑都会变哈希的记录会迫使配置跟着改，那等于没有门禁。
后者内嵌 `model_package_hash`，因此**改动任何模型文件都会使它失效**，必须重跑：
两个保真度是否一致的结论只对当时那份模型成立。
